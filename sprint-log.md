## Iteration 2.1 (testing and initial development)

**Dates:** October 19 - November 8, 2026

### Goals

- implement the prototype stories: create a group and add members, add an expense with an equal split, save and reload data, and show balances
- write and run unit tests that map back to the requirements
- deliver a working prototype with the requirement-to-test traceability matrix

### Results

- test cases TC-001 to TC-036 written, with coverage recorded for each requirement
- unit tests for groups, expenses, the equal split, save and reload, and balances passed; the manual tests were not run
- deliverable doc written

### Retrospective

The prototype unit tests passed. The messy part was coordinating.

1. PR reviews overlapped and we kept stepping on each other's feet. Too many of us were in the same files, so edits and reviews got in each other's way.
2. We underestimated how long the foundation would take. Setup ate more of the iteration than we planned, and the stories on top of it got squeezed.
3. Next time we want about 7 days of buffer at the end so reviews and fixes aren't right up against the deadline.
4. We're bumping required reviews to 2 out of 4, even though the team charter only said 1. One review wasn't catching enough before stuff landed.
5. Vacation plans need at least 2 weeks' notice so we can move work around before someone is out.
